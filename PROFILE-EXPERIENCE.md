# Profile experience

Updated 2026-11-16. Clickable message avatars/names, context authors and notification avatars use the existing accessible profile dialog. Own profile previews lead to editing rather than requesting a conversation with oneself. Industry labels use readable names. Full profiles have a layered banner/avatar composition and mood badge.

Existing public-profile RPCs remain the authority for permitted details. Login email, Auth identifiers, private preferences and hidden employment history are not added to client queries. Existing username cooldown, media validation, blocking/reporting and DM consent remain intact. Empty optional details remain optional; customization is not a prerequisite to chat.

Public visitor messages intentionally retain the minimal guest author projection. Authentication is still required for member profile actions. The full profile route remains the existing application route, avoiding an unnecessary routing migration.
