# Peak Unemployment brand system

The original speech-bubble / mountain mark connects conversation with the space between jobs. Full-name wordmarks and mono/light/dark marks live in `public/brand`; `src/shared/brand.tsx` is the component source. Existing PNG app/social exports and SVG variants remain available.

## Day Shift / Night Shift

| Role | Day | Night |
|---|---|---|
| Background | #F8F7F2 | #11151B |
| Surface | #FFFFFF | #1D232B |
| Text | #171A21 | #F6F5F0 |
| Secondary | #59616B | #B7C0CC |
| Border | #E1DFD8 | #394450 |
| Action | #3652DD | #9AACFF |
| Coral | #FF7058 | #FF957F |

Lime #D7F56A is a small decorative accent. Body text uses legible token variants rather than coral backgrounds as text colors. Space Grotesk carries headings; DM Sans carries conversation and controls. Fonts are self-hosted in public/fonts (SIL Open Font License). No new font or icon packages were introduced.

The editorial headline, stacked physical brand card, room-specific illustrations, and nickname card are bespoke HTML/CSS/SVG composition. Rooms are a discovery section, with a separate compact selector at the conversation itself. No fabricated popularity or presence metrics.
